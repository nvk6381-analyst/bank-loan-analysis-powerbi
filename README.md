# Bank Loan Analysis Dashboard (Power BI)
## Project Overview
This project analyzes bank loan performance using Microsoft Power BI. The dashboard provides business insights into loan applications, funded amounts, repayments, interest rates, debt-to-income ratio, and loan quality.
## Dashboard Highlights
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income Ratio (DTI)
- Good Loan vs Bad Loan Analysis
- Loan Status Summary
- Interactive Filters
  - State
  - Grade
  - Purpose
## Key KPIs
- Loan Applications
- Funded Amount
- Amount Received
- Average Interest Rate
- Average DTI
- Good Loan Percentage
- Bad Loan Percentage
## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset
